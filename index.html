Simulation model

v0.6 foundation
v0.6 Stage 3: core simulation math is now collection-aware. Unboxed floats use the observed CS unbox wear-bucket distribution and dead-zone behavior, then remap through each finish's min/max. Trade-up output float uses normalized input position inside each input skin's own float range. Inventory instances now carry stable case/collection/item identifiers so future cases can share the same engine.

Steam valuation now uses the exact wear/StatTrak snapshot price with no invented within-wear multiplier. CaseLab attempts a limited live Steam Market refresh on launch and on demand; if Steam blocks browser access or rate-limits the request, the baked snapshot remains active. Float premiums are only added when comparable-sales data exists; Stage 3 intentionally applies none. Pattern premiums are stored but not priced yet.

ROI: Gross ROI is the market value of everything still owned plus the gross-equivalent value of sold items, divided by opening spend. Net liquidation ROI applies the 15% Steam sale fee. This prevents the fee-adjusted number from being confused with the pre-fee ROI figures commonly quoted by case calculators.

3D inspect: CaseLab now includes a native rotatable/pinch-zoom 3D viewer using CS2 workshop weapon geometry. The rolled float drives deterministic procedural wear in the native preview. Native skin mapping currently uses the official panorama render as a temporary projection source; it is not Source 2 finish compositing. The EXACT button remains the reference renderer while raw paint-kit textures/material rules are integrated.
