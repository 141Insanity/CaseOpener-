Kilowatt v0.5.0
Case outcomes use the standard CS2 rarity distribution, a separate StatTrak roll, each finish's float limits, and pattern seeds 0–999. Trade-ups use 10 same-rarity/same-StatTrak inputs through Covert, while eligible Covert skins use 5 matching inputs to roll the collection's Rare Special Item pool. Both use the standard output-float formula.

Steam valuation is still a wear-specific price snapshot with a bounded within-wear float adjustment. It is intentionally labeled an estimate. Pattern premiums are stored but not priced yet.

ROI: Gross ROI is the market value of everything still owned plus the gross-equivalent value of sold items, divided by opening spend. Net liquidation ROI applies the 15% Steam sale fee. This prevents the fee-adjusted number from being confused with the pre-fee ROI figures commonly quoted by case calculators.

3D inspect: CaseLab now includes a native rotatable/pinch-zoom 3D viewer using CS2 workshop weapon geometry. The rolled float drives deterministic procedural wear in the native preview. Because true Source 2 finish compositing is not publicly licensed/API-accessible, the EXACT button still opens Skinshotter for pixel-accurate Source 2 wear/pattern rendering.
