Simulation model

v0.6 foundation
v0.6 Stage 1: this build intentionally preserves the v0.5.6 simulation/math while the project is moved onto the new architecture. Float RNG, current trade-up math, pricing, and final 3D materials are scheduled for later v0.6 stages so storage/migration can be validated independently first.

Steam valuation is still a wear-specific price snapshot with a bounded within-wear float adjustment. It is intentionally labeled an estimate. Pattern premiums are stored but not priced yet.

ROI: Gross ROI is the market value of everything still owned plus the gross-equivalent value of sold items, divided by opening spend. Net liquidation ROI applies the 15% Steam sale fee. This prevents the fee-adjusted number from being confused with the pre-fee ROI figures commonly quoted by case calculators.

3D inspect: CaseLab now includes a native rotatable/pinch-zoom 3D viewer using CS2 workshop weapon geometry. The rolled float drives deterministic procedural wear in the native preview. Native skin mapping currently uses the official panorama render as a temporary projection source; it is not Source 2 finish compositing. The EXACT button remains the reference renderer while raw paint-kit textures/material rules are integrated.
