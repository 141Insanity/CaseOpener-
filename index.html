Pricing model

snapshot: Aug 31, 2026
Prices in this prototype are a Steam-market snapshot by exact wear and StatTrak variant. The rolled float then adjusts the wear price within a bounded premium/discount curve. This is an estimate of relative-float value, not a claim that Steam itself publishes sales indexed by float. Pattern premium is currently neutral except the generated pattern seed is stored on every item. Kukri finish premiums use conservative placeholder Steam-equivalent estimates until pattern-specific pricing is wired.

Simulation rules

Rarity is rolled first using 79.92 / 15.98 / 3.20 / 0.64 / 0.26. An item is chosen uniformly inside that rarity. StatTrak is independently rolled at 10%. Float is uniformly generated inside each skin's allowed float range; wear is derived from standard CS2 thresholds. Pattern seed is an integer from 0–999. Selling credits an estimated Steam net amount using a 15% combined fee model.
